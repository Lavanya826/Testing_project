## 📌 Project Overview

**CivicTrack** is a web-based Citizen Complaint Management System designed to simplify the process of reporting and managing public issues.

Citizens can submit complaints related to public problems, while administrators can view complaints, assign departments, update complaint status, and add resolution notes.

The main objective of this project is to understand and implement **Manual Software Testing concepts** by identifying defects, validating functionality, and ensuring the application works as expected.

## 🎯 Project Objectives

- Understand real-world manual testing practices.
- Verify application functionality.
- Identify and report software defects.
- Validate user roles and permissions.
- Test form validations and user interactions.
- Ensure the application behaves according to requirements.

## ✨ Application Features

### 👤 Citizen Module
- Citizen registration and login.
- Submit public complaints.
- Add complaint details and location.
- View submitted complaints.
- Track complaint status.

### 🛡️ Admin Module
- Admin login.
- View all submitted complaints.
- Update complaint status.
- Change complaint priority.
- Assign departments.
- Add resolution notes.
- Delete complaints.
- Monitor complaint progress.

## 🧪 Manual Testing Scope

The following testing activities are covered in this project:

| Testing Type | Description |
|---|---|
| Functional Testing | Verify application functionality |
| UI Testing | Check buttons, forms and interface |
| Smoke Testing | Verify critical application features |
| Sanity Testing | Verify specific changes |
| Integration Testing | Verify citizen and admin interaction |
| Validation Testing | Check input fields and form validations |
| Negative Testing | Test invalid inputs and scenarios |
| Role-Based Testing | Verify citizen and admin permissions |

## 📋 Test Scenarios

Some important test scenarios include:

1. Verify citizen login with valid credentials.
2. Verify login with invalid credentials.
3. Verify complaint submission with valid details.
4. Verify mandatory field validation.
5. Verify whether submitted complaints appear in the admin dashboard.
6. Verify admin can update complaint status.
7. Verify admin can change complaint priority.
8. Verify admin can assign departments.
9. Verify citizen cannot access admin-only controls.
10. Verify complaint deletion functionality.
11. Verify complaint data persistence using local storage.
12. Verify logout functionality.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the downloaded project folder.
3. Locate the `civictrack_admin.html` file.
4. Open the file in any modern web browser.
5. Explore the Citizen and Admin modules.

No additional server installation is required.

## ⚠️ Project Limitations

- Application data is stored in browser LocalStorage.
- Data is limited to the same browser and device.
- It does not use a centralized database.
- Authentication is implemented for demonstration purposes and is not production-grade security.
